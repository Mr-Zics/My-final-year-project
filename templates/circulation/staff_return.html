Circulation Desk Notes

  • When a returned book has waiting reservations, the system automatically marks the copy as RESERVED and sets a 48-hour pickup window for the first student in the queue.
  • If no student is waiting, the copy is automatically returned to AVAILABLE status on the open shelves.
  • If the return is past the due date, an UNPAID fine record is automatically generated for the borrower.
